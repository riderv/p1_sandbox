# AI Context: p1_sandbox (Gamedev Education)
- **Язык/Стек:** C++ (Ортодоксальный стиль, близкий к C, без ислючений, без rtti), библиотека Raylib.
- **Цель проекта:** Написать ascii онлайновый рогалик,
в который можно будет играть по сети.
Оставить возможость расширения до простой 3д графики по типу майнкрафта.
- **Текущая папка проекта:** `~/Projects/p1_sandbox`
- **Что сделано:** 
- Подобранны шрифты, их загрузка.
 
- **Следующий шаг:** Сделать главное меню с пунктами:
- 0. Создать функцию отрисовки текста, где каждая буква растянута на квадрат,
как в snippets/font_preview.cpp/DrawTextCodepointInBox.
Это понадобится для ascii рендера карты прямоугольным шрифтом
типа JetBrains (unscii-8 и так квадратный, должен норм отображаться). 

- 1. Создать/редактировать карту.
- 1.1. Собственно, написать редактор карты,
в котором можно будет выбрать размер карты,
каким тайлом заполнить по умолчанию (отобразить 
список тайлов), сохранить карту.
- 2. Играть на карте.
- 2.1 Выбор карты/файла, загрузка карты, 
спавн указанных на карте монстров (нужен редактор монстров?),
спавн игрока и переход к геймплею.
